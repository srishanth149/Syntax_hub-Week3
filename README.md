# 📰 Web Scraper for Headlines

A Python-based web scraper that collects headlines from multiple news sources and displays them through an interactive Streamlit web interface.

## Features

- Multiple news sources
- Headline extraction
- URL extraction
- Publication time
- Keyword filtering
- CSV export
- JSON export
- Error handling
- Streamlit web interface

## Technologies

- Python
- Requests
- BeautifulSoup
- Streamlit
- Pandas
- RSS feeds

## How to Run

uv sync

uv run streamlit run app.py
